适用设备：你此前使用的 LCTech BL616 适配器。
本包不适用于 Pico 2W、M0S Dock、Ai-M61 或其他板型。

使用步骤
1. 把 ZIP 完整解压到本机“下载”或“桌面”，不要直接在压缩包里运行。
2. 按住适配器 BOOT 键接入 USB，再松开 BOOT。每次仅连接一个待刷设备。
3. 双击 {launcher}。
4. 按回车开始。工具自动查找端口、烧录、校验，无需选择 COM 口和文件。
5. 显示“烧录成功”后，不按 BOOT，拔插一次即可使用。

请用能传输数据的 USB 线。烧录期间不要拔线，通常需要 10–30 秒。
失败时不会显示成功，错误日志保存在同一目录的 logs 文件夹内。
只有 VID 349B / PID 6160 的 BOOT 下载端口会被选中；多个匹配端口时会停止等待。
这里识别的是芯片下载模式，无法据此判断开发板型号，因此仅在上述板型上使用。

{platform_notes}

固件行为
- HS 高速版；默认不呈现 USB 声卡。
- macOS 上需要配套修改后的 CR，通过 HID 命令开启声卡。
- iPad / iPhone 未收到开启命令时保持纯 HID，声音继续使用原播放路径。
- 包含备用陀螺仪校准、声卡切换、实时档仅发送新输入帧，以及 R6 蓝牙连接修复。
- R7 默认回报率为实时档；已有保存的档位会保留。
- 正常启动后长按 BOOT 3 秒，看到三次闪灯后松开，会重启并清除全部设置及配对，
  恢复默认实时档。按住 BOOT 插入 USB 仍是下载模式。
- 认证明确拒绝密钥时清除失效密钥；普通连接超时保留配对。
- 断线后释放主机按键，等待蓝牙资源清理后重连，清理超时会重启适配器。
- 仅擦写本包 Boot2、分区表和固件对应的区域，不执行整片 Flash 擦除。

维护
- 不要自行替换包内的 bin 或配置文件，文件哈希不符会拒绝烧录。
- 维护者打包方式见 source/easy_flash/README.md；普通使用者无需运行源码。
- 固件源码快照、构建方式和第三方来源见 source 与 NOTICE.txt。
- R7 固件已编译并通过主机测试，尚未完成实机烧录验收。
  本包的脚本和离线检查不能替代真实设备烧录验证；Windows 硬件烧录尚未验收。
