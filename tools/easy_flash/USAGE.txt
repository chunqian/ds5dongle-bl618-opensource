DS5Dongle 简易烧录包 — LCTech BL616 / HS 高速版
固件：LCT616-DS5 3.18H-HidAudio-R2

适用设备：你此前使用的 LCTech BL616 适配器。
本包不适用于 Pico 2W、M0S Dock、Ai-M61 或其他板型。

使用步骤
1. 把 ZIP 完整解压到本机“下载”或“桌面”，不要直接在压缩包里运行。
2. 按住适配器 BOOT 键接入 USB，再松开 BOOT。每次仅连接一个待刷设备。
3. Mac 双击 Flash-Mac.command；Windows 双击 Flash-Windows.bat。
4. 按回车开始。工具自动查找端口、烧录、校验，无需选择 COM 口和文件。
5. 显示“烧录成功”后，不按 BOOT，拔插一次即可使用。

请用能传输数据的 USB 线。烧录期间不要拔线，通常需要 10–30 秒。
失败时不会显示成功，错误日志保存在同一目录的 logs 文件夹内。
只有 VID 349B / PID 6160 的 BOOT 下载端口会被选中；多个匹配端口时会停止等待。
这里识别的是芯片下载模式，无法据此判断开发板型号，因此仅在上述板型上使用。

Mac
- 支持 Apple 芯片和 Intel Mac（macOS 11 或更新），自动选择对应的原生程序。
- 不需要 Rosetta、Python、Homebrew、Xcode 或 SDK；运行依赖已随包提供。
- 从网络下载后，macOS 可能要求首次允许运行：在“系统设置 → 隐私与安全性”
  中允许此工具，再重新打开；不要关闭系统的整体安全检查。

Windows
- 支持 64 位 Windows 10 / 11，使用系统自带 Windows PowerShell。
- 不需要 Python、SDK、编译工具链或管理员运行。
- 初次连接 BOOT 下载模式时，等待系统安装 USB 串口驱动，再按回车。
- 若始终没有端口，在设备管理器中检查该设备是否出现 USB 串行设备（COMx）。
  有黄色感叹号时先解决驱动问题；不要把其他 COM 口当成该适配器刷入。
- 单次脚本启动使用进程内 ExecutionPolicy Bypass，不修改电脑的全局执行策略。

固件行为
- HS 高速版；默认不呈现 USB 声卡。
- macOS 上需要配套修改后的 CR，通过 HID 命令开启声卡。
- iPad / iPhone 未收到开启命令时保持纯 HID，声音继续使用原播放路径。
- 包含此前的备用陀螺仪校准修复及 R2 声卡切换时序修复。
- 仅擦写本包 Boot2、分区表和固件对应的区域，不执行整片 Flash 擦除。

维护
- 不要自行替换包内的 bin 或配置文件，文件哈希不符会拒绝烧录。
- 维护者打包方式见 source/easy_flash/README.md；普通使用者无需运行源码。
- 固件源码快照、构建方式和第三方来源见 source 与 NOTICE.txt。
- Apple 芯片原生程序已验证启动、离线生成烧录镜像，以及脚本成功/失败处理。
  本版本尚未完成 ARM64 程序和 Windows 程序的硬件烧录验收；固件本身保持原已验证版本。
